Select What's new in the top bar to read the changes to the application, newest first, grouped by month and ranked by impact. A number beside it counts the changes made since you last looked, and opening the list clears it; a new account starts with no number.

## Technical notes

Entries are files in `changelog.d/`; `uv run python manage.py changelog` generates `CHANGELOG.md` and `--check` fails when it is stale. The seen state is a per-user preference, so no migration is needed. Client portal accounts do not have What's new.
